# 今日鸡汤 · ChickenSoup Daily

每天一句，好好生活。一个纯静态的个人语录小站：按日期自动轮换「今日一汤」，收录四大主题——

| 主题 | 内容 | 数据 |
|---|---|---|
| **毛选语录** | 《毛泽东选集》四卷经典语录，按原文篇目编排，附诗词名句 | `data/maoxuan.js` |
| **三十六计** | 六套三十六计全录：解语原文 + 白话释义 + 经典典故 | `data/sanshiliuji.js` |
| **天道众生相** | 王志文《天道》台词：网络热传"万般努力"段落（置顶）+ 剧中经典台词分辑 | `data/tiandao.js` |
| **自我觉醒** | 人生开窍五阶：祛魅 · 忘情 · 归已 · 泯生 · 回归（附灵感原图） | `data/juexing.js` |

## 本地使用

方式一（最简单）：直接双击 `index.html` 用浏览器打开即可，全部功能可用。

方式二（推荐，体验更佳）：

```bash
# 在项目目录下任选其一
python -m http.server 8642
npx serve .
```

然后访问 <http://127.0.0.1:8642>。

## 功能

- **今日一汤**：按日期确定性轮换，每天自动换一条，同一主题内每天不重复；首页可切换三大主题
- **换一条**：随机换汤（不改变「今日」的既定推荐，可一键回到今日）
- **回味前七天**：首页可回看最近七天的每日推荐
- **毛选语录**：分卷浏览全部篇目，篇目手风琴展开，支持全文搜索，今日语录自动高亮
- **三十六计**：按六套分类的卡片墙，点开看原文 / 释义 / 典故
- **自我觉醒**：五窍时间轴 + 微信原图展示
- **收藏**：点 ♡ 收进「我的汤碗」（localStorage 持久化），随时复制
- **复制**：所有语录一键复制为「内容 + 出处」格式
- 响应式布局，手机可用；无任何构建依赖

## 如何加新主题 / 新语录

数据与界面分离，扩充只需改 `data/` 下的 JS 文件（用普通 `<script>` 引入，挂到 `window` 上），无需构建：

1. 新语录：往对应主题的 `quotes` 数组里加 `{ text, tag }` 即可
2. 新主题：新建数据文件 + 在 `app.js` 里加一个路由和入口卡（仿照现有主题即可）

后续主题（用户陆续提供）可直接按此扩展。
